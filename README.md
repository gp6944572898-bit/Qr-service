# Динамические QR-коды

Сервис генерирует QR-код один раз, но ссылка «внутри» него меняется в панели
управления в любой момент — сама картинка QR не меняется, потому что она
кодирует не целевой сайт, а адрес вида `/r/КОД`, который на сервере
перенаправляет туда, куда указано сейчас.

## Как это устроено

- `server.js` — Express-сервер: авторизация, API для QR-кодов, редирект `/r/:code`
- `db.js` — хранилище на Postgres (рассчитано на бесплатный Neon)
- `public/` — фронтенд панели управления (обычный HTML/CSS/JS, без сборки)
- `scripts/create-admin.js` — создание единственного логина/пароля администратора

## Деплой: Render (сервер) + Neon (база данных)

Бесплатный Postgres на самом Render удаляется через 30 дней, поэтому базу
берём отдельно на Neon — там бесплатный тариф постоянный.

### 1. База данных на Neon

1. Зарегистрируйтесь на [neon.tech](https://neon.tech), создайте проект
2. В Dashboard → Connection string скопируйте строку вида
   `postgresql://user:password@ep-xxxx.neon.tech/neondb?sslmode=require`

### 2. Локально: создать администратора

```bash
npm install
cp .env.example .env
# впишите в .env скопированный DATABASE_URL и свой JWT_SECRET
npm run create-admin      # задать логин и пароль — сохранится сразу в Neon
```

### 3. Сервер на Render

1. Залейте папку проекта в репозиторий на GitHub
2. На [render.com](https://render.com) → New → Web Service → подключите репозиторий
3. Настройки: Build Command `npm install`, Start Command `npm start`
4. В разделе Environment добавьте переменные:
   - `DATABASE_URL` — та же строка от Neon
   - `JWT_SECRET` — та же случайная строка, что и локально
   - `BASE_URL` — заполните **после** первого деплоя, когда Render выдаст
     адрес вида `https://ваш-сервис.onrender.com` (впишите его сюда и
     передеплойте — именно этот адрес будет "зашиваться" в QR-коды)
5. Deploy. Через пару минут сервис будет доступен по адресу от Render.

Бесплатный тариф Render засыпает после 15 минут простоя и просыпается
30–60 секунд при первом запросе — это нормально для тестового проекта.

## Как пользоваться

1. Откройте адрес сервиса, войдите под логином/паролем, заданным на шаге 2
2. Вставьте ссылку и нажмите «Создать QR-код» — появится карточка с картинкой
3. Скачайте/распечатайте картинку (правый клик → «Сохранить изображение»)
4. Когда нужно поменять, куда ведёт код — впишите новую ссылку в то же поле
   и нажмите «Сохранить». Картинка остаётся той же

## Локальный запуск (без деплоя)

```bash
npm install
cp .env.example .env   # впишите DATABASE_URL от Neon и JWT_SECRET
npm run create-admin
npm start
```

Откроется на `http://localhost:3000` — подойдёт для разработки и проверки,
но QR-коды с адресом localhost не откроются с чужого телефона.

## Что стоит доделать позже

- Статистику переходов (сколько раз, когда сканировали)
- Ограничение попыток входа (rate limiting) на `/api/login`
- Собственный домен вместо `onrender.com` — тогда QR-коды переживут даже
  смену хостинга (достаточно поменять BASE_URL и перевыпустить редиректы)
